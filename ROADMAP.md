# ROADMAP --- Fullstack Developer Journey

Version: 1.0 Timeline mục tiêu: 09/2026 → 2028

## 1. Tổng quan

  Giai đoạn   Thời gian          Trọng tâm
  ----------- ------------------ ------------------------------------------------
  Level 0     Tuần 1             Programming thinking
  Level 1     Tháng 1--2         JavaScript fundamentals
  Level 2     Tháng 3--4         Problem solving + Data Structures & Algorithms
  Level 3     Tháng 5--7         Web fundamentals
  Level 4     Tháng 8--10        React + TypeScript
  Level 5     Tháng 11--14       Backend + Database
  Level 6     Tháng 15--17       Fullstack
  Level 7     Tháng 18--20       Production + Portfolio
  Level 8     Trước internship   CV + Interview + Apply

Lịch trên chỉ là khung. Năng lực quyết định việc chuyển level.

## 2. Level 0 --- Programming Thinking

Mục tiêu: - Hiểu Input → Process → Output. - Biết phân tích requirement
trước khi code. - Viết pseudocode. - Làm quen với tư duy điều kiện và dữ
liệu.

Bài nền: 1. Kiểm tra tuổi ≥ 18. 2. Phân loại số dương/âm/0. 3. Tìm max
của 3 số không dùng Math.max(). 4. Phân loại điểm sinh viên:
Excellent/Good/Average/Weak.

## 3. Level 1 --- JavaScript Fundamentals

Mục tiêu: - Variables: let/const. - Data types. - Operators. - if/else,
switch. - for, while. - Functions. - Arrays. - Objects. - String. -
Basic input/output. - Error handling cơ bản.

Mục tiêu đầu ra: - 100--150 bài nhỏ trong giai đoạn nền tảng/problem
solving đầu. - Có thể tự viết chương trình nhỏ không cần tutorial.

## 4. Level 2 --- Problem Solving + DSA

Tập trung: - Complexity / Big O cơ bản. - Array/String. - Searching. -
Sorting. - Stack. - Queue. - Linked List. - Hash/Map/Set. - Recursion cơ
bản. - Tree/Graph ở mức nền tảng. - Pattern solving.

Mục tiêu không phải học thuộc thuật toán mà hiểu khi nào và tại sao dùng
chúng.

## 5. Level 3 --- Web Fundamentals

Tập trung: - HTML. - CSS. - JavaScript trên browser. - DOM. - Events. -
Forms. - HTTP. - Request/Response. - JSON. - REST/API fundamentals. -
Browser basics.

Project nhỏ: - Todo/Task app. - Form/app có tương tác với API.

## 6. Level 4 --- React + TypeScript

Tập trung: - React components. - Props. - State. - Events. - Hooks. -
Forms. - Routing. - API calls. - Component design. - State management ở
mức cần thiết. - TypeScript fundamentals.

Không học React như bộ syntax độc lập; phải hiểu browser/web trước.

## 7. Level 5 --- Backend + Database

Stack: - Node.js. - Express trước. - Sau khi hiểu backend mới tiếp cận
NestJS. - PostgreSQL. - Git/GitHub.

Database phải học SQL trước ORM.

SQL trọng tâm: - CREATE. - SELECT. - INSERT. - UPDATE. - DELETE. -
WHERE. - ORDER BY. - GROUP BY. - JOIN. - INDEX. - PRIMARY KEY. - FOREIGN
KEY. - UNIQUE. - Normalization. - Transaction.

Sau khi hiểu SQL mới học ORM như Prisma/Drizzle/TypeORM.

## 8. Level 6 --- Fullstack

Mục tiêu: Frontend → API → Backend → Database.

Project chính: \### Project 1 --- Todo / Task Management Có CRUD,
authentication ở mức phù hợp, database, API và frontend.

### Project 2 --- E-commerce

Sản phẩm, người dùng, giỏ hàng, order và các luồng nghiệp vụ phù hợp.

### Project 3 --- Internship Management System

Domain chính: - Student. - Company. - Job. - Application. - Interview. -
Recruiter.

Đây là project quan trọng để thể hiện khả năng phân tích domain và thiết
kế hệ thống.

## 9. Level 7 --- Production + Portfolio

Tập trung: - Git workflow. - Branching. - Pull request mindset. -
Environment variables. - Docker/Compose. - Testing ở mức phù hợp. -
Logging. - Error handling. - Deployment. - Basic production thinking.

DevOps không phải mục tiêu chính; chỉ học đủ để build/deploy/maintain
project.

Portfolio: - 3--4 project tốt. - README rõ ràng. - Screenshots. - Tech
stack. - Architecture. - Installation. - Demo. - GitHub history có chất
lượng.
